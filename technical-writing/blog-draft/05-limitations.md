# ⑤ 주의할 점: 언제 쓰면 위험한가

작성 상태: 본문 작성 대기. 작성 범위는 [문서 작성 계획서](../WRITING_PLAN.md)를 따른다.

## 본문에서 설명할 질문

- Worker 수와 Polling 주기가 DB 조회 부하에 어떤 영향을 주는가?
- claimToken이 보장하는 결과 반영과 이미지 생성의 중복 실행은 어떻게 구분해야 하는가?
- 처리 기한이 생성 시간보다 짧거나 요청 유입이 처리 속도보다 빠르면 어떤 문제가 생기는가?
- Worker별 동시성 상한과 전체 처리 용량은 어떻게 구분해야 하는가?
- 어떤 관측 결과가 나오면 DB Job Queue 유지와 다른 비동기 처리 방식의 전환을 다시 검토할 것인가?

[04단계의 보장 범위와 구현 제약](../04-reliability-hardening/README.md), [06단계의 측정 지표와 결과 범위](../06-final-300-job-measurement/README.md)를 바탕으로 작성한다. 실제 측정에서 확인한 한계와 설계상 예상한 한계를 구분한다.
