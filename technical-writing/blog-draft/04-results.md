# ④ 달라진 점과 근거: 해 보니 무엇이 달라졌나요?

작성 상태: 검증·측정 결과를 확보한 뒤 본문을 작성합니다. 현재 회귀 검증 상태는 [05단계](../05-regression-verification/README.md#현재-검증-상태)를 참조합니다.

## 본문에서 설명할 질문

- 같은 다섯 신뢰성 조건에서 최소 구조의 RED와 개선 구조의 GREEN 결과는 어떻게 달라졌나요?
- 별도 Web·Worker JVM에서 HTTP 요청 300건을 처리했을 때 접수와 최종 결과는 모두 추적됐나요?
- 기본 검증 통과 후 요청 수 또는 HTTP 동시성을 늘리면 작업 대기와 재시도, 완료 시간이 어떻게 변하나요?

## 확보할 근거

RED/GREEN 결과는 [05단계의 대응표](../05-regression-verification/README.md)를 기준으로 정리합니다. 300건 기본 검증과 추가 부하의 실행 조건, 통과 조건, 확대 기준은 [06단계](../06-final-300-job-measurement/README.md#측정-범위와-확대-기준)를 따릅니다. 결과를 확보한 뒤 실제 실행 조건과 측정 파일을 연결합니다.

정상 부하 측정과 장애 복구 테스트를 서로 다른 근거로 설명하고, 모의 이미지 생성 조건에서 얻은 결과의 범위를 명시합니다.

시각 자료: RED/GREEN 대응표, 300건 결과 요약표, 추가 부하의 실행 조건과 결과 비교표.
